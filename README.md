# Design-and-Development-of-an-Advanced-LLM-Pipeline-for-Retrieval-Augmented-Question-Answering-
This project develops an Adaptive RAG system for scientific question answering using the QASPER dataset. It combines dense and BM25 retrieval, expands evidence when confidence is low, and compares performance against standard top-5 and top-8 RAG baselines using F1 scores.
